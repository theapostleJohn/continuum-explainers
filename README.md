# Continuum setup explainer media

Eight short explainer videos that play inside the Continuum setup wizard, one before each step, with captions. Produced for Agent Fluency / Continuum. The files under `media/` are 720p copies cut into parts under 20 MB so they can be served through jsDelivr; the 1080p masters are kept with the project.

- `media/<nn>-<name>[-partN].mp4` and the matching `.vtt` captions
- `media/<nn>-<name>.jpg` poster frames
- `hosting.json` lists the parts per video and the CDN base URL once published
