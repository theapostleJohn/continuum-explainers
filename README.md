# Continuum setup explainer media

Eight short explainer videos that play inside the Continuum setup wizard, one before each step, with captions. Together they also form the Continuum course. Produced for Agent Fluency / Continuum.

- `media/<nn>-<name>.mp4`: 720p copies, each under 19 MB so they can be served through jsDelivr; the 1080p masters are kept with the project
- `media/<nn>-<name>.vtt`: captions; `media/<nn>-<name>.jpg`: poster frames
- `hosting.json`: the parts per video and the CDN base URL

Versions: `v1` (first NotebookLM cut), `v2` (rebuilt in the Agent Fluency style, constitution-based setup).
